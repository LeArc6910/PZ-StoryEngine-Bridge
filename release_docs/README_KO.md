# StoryEngine 브릿지

프로젝트 좀보이드 모드 **StoryEngine**(Build 42.20 이상)의 AI 기능(무전 대화, AI 디렉터, 일지, 독백)을
**본인의 API 키**로 AI 서비스와 연결해 주는 선택 프로그램입니다.
비공식 팬 제작물이며 The Indie Stone, OpenAI, Anthropic과 관계가 없습니다.

모드는 브릿지 없이도 동작합니다(규칙 기반 사건과 준비된 문장). 브릿지는 AI가 쓰는 문장과 판단만 더합니다.

## 누가 실행하나요

- 싱글플레이: 본인
- 멀티플레이: **호스트(서버) PC 한 대만**. 접속하는 사람은 창작마당 모드만 있으면 됩니다.

## 설치

1. 폴더를 원하는 곳에 압축 해제합니다 (예: `문서\StoryEngineBridge`).
2. `StoryEngineBridge.exe`를 실행합니다. 처음 실행하면 설정 마법사가 묻습니다.
   - AI 서비스: OpenAI, Anthropic(Claude), 테스트 모드(AI 없음, 비용 없음)
   - API 키 (입력 내용은 보이지 않고, exe 옆의 `config.toml`에만 저장됩니다)
   - 게임 데이터 폴더 (기본값 `%USERPROFILE%\Zomboid\Lua\StoryEngine`이 싱글과 인게임 호스트에 맞습니다)
3. 플레이하는 동안 창을 열어 두세요. 게임이 브릿지를 찾으면 "AI 연결됨"이 뜹니다.

나중에 설정을 바꾸려면 `StoryEngineBridge.exe --setup`을 실행하거나 `config.toml`을 고치세요(`config.example.toml` 참고).

## 무엇을 어디로 보내나요

브릿지는 **이 PC에서 선택한 AI 서비스(OpenAI 또는 Anthropic)로 직접** 요청을 보내며, 각 서비스의 약관과 개인정보 처리방침을 따릅니다.
모드 제작자나 다른 서버로는 아무것도 보내지 않습니다.

보내는 것: 캐릭터 이름과 직업, 게임 속 요약(장소, 시각, 처치 수, 부상, 무들, 날씨, 퀘스트 사건),
플레이어가 모드의 무전 창에 입력한 대화, 이어지는 내용을 위한 이전 일지·무전 문장.
보내지 않는 것: 스팀 ID, 계정 이름, 다른 플레이어의 IP, 게임 밖의 정보.
서버에 함께하는 사람들에게 무전 대화가 AI 서비스로 전송된다는 점을 알려 주세요.

## 비용

API 사용 요금은 AI 서비스가 **본인에게** 청구합니다. 브릿지는 기본으로 시간당 120건까지만 요청합니다
(`config.toml`의 `[limits] requests_per_hour`). 사용량은 각 서비스의 대시보드에서 확인하세요.

## 건드리는 파일

`Zomboid\Lua\StoryEngine\`(요청·응답 파일, 연결 신호, 일지 텍스트)와 자기 폴더만 사용합니다.
게임이나 다른 프로그램을 수정하지 않습니다. 삭제하려면 창을 닫고 폴더를 지우면 됩니다(저장된 API 키도 함께 지워집니다).

## 보안 안내

- `config.toml`에는 API 키가 들어 있습니다. 공유하거나 업로드하지 마세요.
- exe는 동봉된 소스 코드를 PyInstaller로 묶은 것입니다. 일부 백신이 PyInstaller 프로그램을 잘못 탐지할 수 있습니다.
  다운로드 페이지에 공개한 SHA256과 zip 파일을 비교하거나, 파이썬 소스를 직접 실행할 수 있습니다.
- AI가 쓴 문장은 틀리거나 예상과 다를 수 있습니다. 프롬프트로 게임 세계와 캐릭터 안에서 말하도록 제한하지만, 사람이 검토하지는 않습니다.
